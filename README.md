# 🚀 Customer Segmentation using KMeans (Streamlit App)

## 📌 Project Overview
This project is a Machine Learning web app that performs **customer segmentation** using the K-Means clustering algorithm.  
Users can input customer details and get the predicted segment instantly.

---

## 🎯 Problem Statement
Businesses need to understand their customers to:
- Improve targeting
- Increase sales
- Personalize marketing strategies  

This app groups customers into segments based on behavior.

---

## 🧠 Model Used
- Algorithm: K-Means Clustering
- Library: Scikit-learn
- Features used:
  - Age
  - Average Spend in Minute
  - Visit Per Week
  - Promotion Interest

---

## ⚙️ Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

---

## 📊 How it Works
1. User inputs customer details  
2. App processes the data  
3. Pre-trained KMeans model predicts cluster  
4. Output shows customer segment
